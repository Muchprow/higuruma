# Higuruma

Lightweight mod manager for Minecraft, built with [Hakari](https://github.com/Muchprow/hakari).

Supports **Modrinth**, **CurseForge**, and **GitHub** sources.

## Status

Early development.

## Features

- Search and install mods from multiple sources
- Manage installed mods (update, remove, disable)
- Profiles — save and share your mod setup
- Fabric, Forge, NeoForge support
- Lightweight, no Electron
